01 / DISCOVER

Stop losing good repositories in a sea of tabs.

  • Personal categories + status
  • AI score / judgement

03 / RUN

05 / GUARDED

Built into HOL Guard. Your agent asks before it touches anything.

Repo Notebook's MCP server ships with HOL Guard from version 3.52.0, the open-source layer from Hashgraph Online that decides what AI coding agents may run. Turn it on, and your agent can browse your collection freely. Saving, cloning or removing a repository always waits for your approval.

WHY REPO NOTEBOOK?

GitHub stores repositories.
Repo Notebook stores context.

The goal is not another bookmark list. It is a working memory for developers, researchers and builders who constantly find useful code and want to understand, compare, classify and actually run it later.
