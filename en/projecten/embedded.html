01 THE PROBLEM

Software only gets really interesting when it touches the physical world. These experiments explore how small, cheap microcontrollers bridge the gap between sensors, screens and the AI tools I build.

02 WHAT IT DOES
ESP32 prototypes
Custom firmware for microcontrollers with Wi-Fi and Bluetooth: measuring, displaying, controlling.
Displays & interfaces
Small screens and controls that make a device understandable without a manual.
Link with software
Devices that talk to the desktop tools and assistants I build — hardware as an extension of the software.
Off-grid communication
Experiments with LoRa mesh for communication without internet or network coverage.
03 WHAT I LEARNED
Hardware is unforgiving: a wrong resistor or a timing error can't be refactored away. That forces you to start small, measure everything and only then expand — exactly the approach I use in software too.
