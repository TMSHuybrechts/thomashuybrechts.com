01 THE PROBLEM

A growing local AI lab quickly becomes a collection of separate services: containers, automations, model servers and GPU workflows, each with its own window. Starting and checking everything separately takes time and goes wrong.

02 WHAT IT DOES
Master command centre
One parent dashboard to wake, validate and control the whole cluster — with a start-up flow that checks network, infra node, AI node, Ollama and OpenClaw step by step.
AI mode & travel mode
The primary AI node stays reachable, even when the machine isn't physically at home, via an overlay network and reconnect logic.
Docker module
Overview and manage containers from the dashboard instead of separate terminals.
n8n automation
The automation engine as its own module, alongside the rest of the cluster.
Local models
Ollama and OpenClaw linked: start models and connect them to the rest of the stack.
ComfyUI / GPU workflows
A separate view for image generation and GPU work, as a module of the same whole.
03 WHAT I LEARNED
The modules — Docker, n8n, Ollama, ComfyUI — aren't separate projects but windows onto one system. The real value was in the start-up flow and reconnect logic that turn separate services into one reliable cluster.
