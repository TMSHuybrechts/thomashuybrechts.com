Repo Notebook for Obsidian

An Obsidian plugin that brings Repo Notebook into your own vault, with BRAT releases and an MCP link so AI assistants can work directly with your notes.

Status
In active development
Role
Design & development
Stack
TypeScript · Obsidian API · BRAT · MCP
RESULT

Repo knowledge and an AI link (MCP) straight in your Obsidian vault, with BRAT releases.

Talk to me about this ↗ Read how it works ↓
01 THE PROBLEM

Many makers live in Obsidian. A separate desktop app is then one place too many. Knowledge about repositories belongs next to your other notes — searchable, linkable and yours.

02 WHAT IT DOES
Everything in your vault
Repositories become plain Markdown notes with frontmatter. They work with your existing tags, links and graph view.
BRAT releases
Install and update via BRAT, without waiting for the official community store. Fast iteration with real users.
MCP link
An MCP server makes the vault reachable for AI assistants such as Claude: searching your repo notes, requesting summaries, letting them add suggestions.
Same brain as Repo Notebook
The analysis and suggestion logic is shared with the desktop app, so both deliver the same quality.
03 WHAT I LEARNED
Building a plugin forces you to make your core small and portable. What happened ‘by itself’ in the desktop app had to become explicit and testable here — and that made the desktop app better too.
