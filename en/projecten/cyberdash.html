01 THE PROBLEM

Security work is spread across dozens of separate command-line tools, each with its own output. I wanted one place that brings together scanners, OSINT and an isolated practice lab — and an exercise in architecture and integration at the same time.

02 WHAT IT DOES
One web interface
Scanners, OSINT tools and lab management behind one modular dashboard instead of separate terminals.
Local AI assistant
A local language model as an assistant in the interface, so no data goes to the cloud.
Tool wrappers
Clean wrappers around well-known security tools, with the results neatly shown in the interface.
OSINT module
Open-source intelligence tools bundled in one place.
Isolated practice lab
A container-based lab for experimenting safely and in isolation.
03 WHAT I LEARNED
The challenge wasn't in the individual tools but in the architecture around them: connecting modules cleanly, showing output uniformly and keeping everything safe and isolated. Publicly I present this as integration and design work, not as live security tooling.
