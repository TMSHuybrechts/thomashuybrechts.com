Repo Notebook per Obsidian

Un plugin Obsidian che porta Repo Notebook nel tuo vault, con release BRAT e un collegamento MCP così gli assistenti AI possono lavorare direttamente con le tue note.

Tipo
Plugin Obsidian
Stato
In sviluppo attivo
Ruolo
Design & sviluppo
Stack
TypeScript · Obsidian API · BRAT · MCP
RISULTATO

Conoscenza sui repo e un collegamento AI (MCP) direttamente nel tuo vault Obsidian, con release BRAT.

Parliamone ↗ Scopri come funziona ↓
01 IL PROBLEMA

Molti maker vivono in Obsidian. Un'app desktop separata è allora un posto di troppo. La conoscenza sui repository deve stare accanto alle altre note — ricercabile, collegabile e tua.

02 COSA FA
Tutto nel tuo vault
I repository diventano normali note Markdown con frontmatter. Funzionano con i tuoi tag, link e graph view esistenti.
Release BRAT
Installare e aggiornare tramite BRAT, senza aspettare lo store ufficiale della community. Iterazione rapida con utenti veri.
Collegamento MCP
Un server MCP rende il vault accessibile ad assistenti AI come Claude: cercare nelle note sui repo, chiedere riassunti, far aggiungere suggerimenti.
Stesso cervello di Repo Notebook
La logica di analisi e suggerimento è condivisa con l'app desktop, così entrambe offrono la stessa qualità.
03 COSA HO IMPARATO
Costruire un plugin ti obbliga a rendere il nucleo piccolo e portabile. Ciò che nell'app desktop andava ‘da sé’ qui doveva diventare esplicito e testabile — e ne ha beneficiato anche l'app desktop.
