OBSIDIAN · PLUGIN · MCP

Repo Notebook para Obsidian

Um plugin do Obsidian que leva o Repo Notebook para o seu próprio vault, com releases BRAT e uma integração MCP para que assistentes de IA possam trabalhar diretamente com as suas notas.

Tipo
Plugin do Obsidian
Estado
Em desenvolvimento ativo
Função
Design & desenvolvimento
Stack
TypeScript · Obsidian API · BRAT · MCP
RESULTADO

Conhecimento de repos e uma ligação de IA (MCP) diretamente no seu vault do Obsidian, com releases BRAT.

Fale comigo sobre isto ↗ Leia como funciona ↓
01 O PROBLEMA

Muitos makers vivem no Obsidian. Uma app de desktop à parte é então um sítio a mais. O conhecimento sobre repositórios deve estar ao lado das outras notas — pesquisável, ligável e seu.

02 O QUE FAZ
Tudo no seu vault
Os repositórios tornam-se notas Markdown normais com frontmatter. Funcionam com as suas tags, links e graph view existentes.
Releases BRAT
Instalar e atualizar via BRAT, sem esperar pela community store oficial. Iteração rápida com utilizadores reais.
Integração MCP
Um servidor MCP torna o vault acessível a assistentes de IA como o Claude: pesquisar nas notas de repos, pedir resumos, deixar adicionar sugestões.
O mesmo cérebro que o Repo Notebook
A lógica de análise e sugestões é partilhada com a app de desktop, para que ambas tenham a mesma qualidade.
03 O QUE APRENDI
Construir um plugin obriga a tornar o núcleo pequeno e portável. O que na app de desktop acontecia ‘sozinho’ teve aqui de ficar explícito e testável — e a app de desktop também melhorou com isso.
