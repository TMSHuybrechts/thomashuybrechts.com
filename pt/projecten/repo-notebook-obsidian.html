Repo Notebook para Obsidian

Um plugin do Obsidian que coloca a tua prateleira do Repo Notebook dentro do teu próprio vault: cada repositório GitHub guardado passa a ser uma nota, os repos relacionados passam a ser wikilinks, e clonar, instalar e executar ficam a um comando de distância.

RESULTADO

Toda a tua coleção do GitHub como notas ligadas no Obsidian, sincronizada nos dois sentidos com a app.

Plugin no GitHub ↗ A app Repo Notebook ↗ Leia como funciona ↓
01 O PROBLEMA

O Repo Notebook guardava a minha coleção do GitHub numa app própria, mas as minhas notas estão no Obsidian. Dois sítios significam trabalho a dobrar: o que sabes sobre um repo deve ficar junto do resto do teu conhecimento, pesquisável e com ligações, sem ficar dessincronizado.

02 O QUE FAZ
Cada repo uma nota
Uma nota Markdown por repo com frontmatter (estrelas, linguagem, tópicos, estado, cluster, saúde), um resumo, o parecer da IA, os ficheiros principais e o README. Mais uma nota de índice por cluster e estado.
Repos relacionados como wikilinks
As ligações do grafo de conhecimento da app passam a ser [[wikilinks]] a sério, com o motivo ao lado. Assim, a vista de grafo do Obsidian mostra o teu mapa completo de repos. Etiquetas como #repo/taal/python dão grupos de cor.
Sincronização nos dois sentidos
Altera o teu estado, categoria ou notas no Obsidian e, pouco mais de um segundo depois, aparece na app, e vice-versa. O teu bloco de Notas nunca é substituído; um repo apagado é marcado, não eliminado.
Painel lateral com ações
Pesquisa, filtros de estado, uma lista A–Z e um menu de contexto com clonar, instalar, iniciar, parar, log e git pull. Se a app estiver desligada, ler, sincronizar e adicionar repos continuam a funcionar.
Tabela Bases
Uma tabela pronta a usar para o Obsidian Bases: todos os repos, ‘para experimentar’, ‘clonados’ e uma vista por cluster.
Instalar em 3 passos
Instala o BRAT a partir dos plugins da comunidade, escolhe ‘Add beta plugin’ e cola TMSHuybrechts/obsidian-repo-notebook. Depois o BRAT mantém o plugin atualizado sozinho.
03 O QUE APRENDI
A pergunta mais difícil não foi técnica, mas sim: o que é de quem? Assim que ficou definido que parte de uma nota é gerida pela app e que parte é tua, a sincronização nos dois sentidos tornou-se fiável. A lógica central funciona sem o Obsidian e está testada contra uma pequena versão simulada da API do Obsidian; uma sincronização de 122 repos demora cerca de 0,3 segundos.
