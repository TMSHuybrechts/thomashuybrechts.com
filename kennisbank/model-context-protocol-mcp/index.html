Model Context Protocol (MCP)

AI koppelen aan je eigen software

MCP is een open standaard die bepaalt hoe AI-modellen en agents tools, databronnen en diensten aansluiten.

Wat is het?

MCP (Model Context Protocol, eind 2024 gelanceerd door Anthropic en sinds december 2025 ondergebracht bij de Agentic AI Foundation van de Linux Foundation) is een universele stekker tussen een LLM en de buitenwereld. In plaats van voor elke tool een maatwerkintegratie te bouwen, spreek je één protocol. Een MCP-server stelt tools, data en prompts beschikbaar; een MCP-client in de agent gebruikt ze.

Hoe werkt het technisch?

  • Client–server-model: de agent-applicatie (host) bevat MCP-clients; elke client verbindt met een MCP-server die een systeem ontsluit (bijv. een database, GitHub of een CRM).
  • Drie bouwstenen: servers bieden tools (acties), resources (data zoals bestanden en records) en prompts (herbruikbare instructiesjablonen).
  • Capability discovery: de client vraagt op welke tools beschikbaar zijn en geeft die beschrijvingen aan het LLM, dat kiest welke het aanroept.
  • Gestandaardiseerde berichten: communicatie loopt via een vast formaat (JSON-RPC), onafhankelijk van model of leverancier.

Wat kun je ermee bouwen?

  • Een toolbibliotheek die al je agents delen: één keer bouwen, overal gebruiken.
  • Agents die live in bedrijfs­systemen werken: orders opzoeken, tickets aanmaken, bestanden lezen.
  • Lokale en privacyvriendelijke opstellingen, omdat MCP-servers ook op eigen infrastructuur draaien.

Commercieel gebruik

Forse besparing op integratie­kosten: N tools plus M agents vergt nog maar N+M koppelingen in plaats van N×M. Herbruikbare MCP-servers zijn verkoopbare componenten. Integratiewerk verandert van maatwerkproject in configureerbaar product.

Sterke combinaties

MCP + RAG: kennisbronnen als MCP-resources ontsluiten. MCP + supervisor–worker: alle workers delen dezelfde toolset via MCP. MCP + sandboxing: MCP-servers met minimale rechten beperken wat een agent kan aanrichten.

Belangrijkste 20%

  • MCP standaardiseert de aansluiting, niet de beveiliging: bepaal zelf welke rechten elke server krijgt.
  • Goede toolbeschrijvingen zijn cruciaal — het LLM kiest op basis van die teksten welke tool het gebruikt.

Praktijkvoorbeeld (fictief)

Een marketingbureau bouwt MCP-servers voor zijn analytics-, CMS- en plannings­systemen. Elke nieuwe agent — content, rapportage, SEO — gebruikt direct dezelfde koppelingen. Nieuwe agents zijn daardoor in dagen in plaats van weken live.
