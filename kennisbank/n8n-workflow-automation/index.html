n8n Workflow Automation

Processen automatiseren met n8n

n8n is een fair-code workflow-tool (Sustainable Use License, dus niet open source) waarmee je zonder veel code systemen aan elkaar knoopt en bedrijfsprocessen automatiseert.

Wat is het?

n8n is een visueel automatiseringsplatform. Je knoopt blokken (nodes) aan elkaar: een trigger start, acties volgen. Denk aan Zapier, maar self-hostbaar en flexibeler.

Hoe werkt het technisch?

  • Elke workflow start met een trigger-node: webhook, cron-schedule, e-mail of app-event.
  • Daarna volgen actie-nodes: API-calls, databasequeries, e-mails, AI-stappen.
  • Data stroomt als JSON door de workflow; je transformeert het met mapping-nodes.
  • Conditionele logica (if/switch) en loops bepalen het pad.
  • Eigen JavaScript of Python voeg je toe via code-nodes.
  • Self-hosten kan via Docker; credentials beheer je centraal. Zelf hosten betekent zelf patchen: n8n had in 2025-2026 kritieke lekken (o.a. CVE-2026-21858); update tijdig en zet de editor niet open op internet.

Wat kun je ermee bouwen?

  • Lead-pipelines: formulier → CRM → AI-scoring → opvolgmail.
  • Factuurverwerking: Peppol-facturen inlezen (in België verplicht voor B2B sinds 1/1/2026), pdf’s van buitenlandse leveranciers uitlezen, boeken in boekhouding.
  • Notificaties en escalaties naar Slack of e-mail.
  • Data-synchronisatie tussen webshop, CRM en boekhouding.

Commercieel gebruik

automatiseringsopdrachten voor kmo’s zijn een verkoopbare dienst. Je levert implementatie plus maandelijks beheer. Workflows bouwen en beheren voor klanten mag onder de licentie; n8n zelf als platform of white-label aanbieden waarop klanten workflows bouwen, vraagt een commerciële licentie. Self-hosten houdt licentiekosten laag en kan data binnen de EU houden, als ook de server en gekoppelde diensten (bv. LLM-API’s) in de EU verwerken.

Sterke combinaties

  • LLM’s: classificeren, samenvatten en teksten genereren in workflows.
  • Webhooks: realtime triggers vanuit elke bron.
  • Vector databases/RAG: antwoorden vanuit eigen bedrijfskennis.
  • Docker: betrouwbaar self-hosten en updaten.
  • Monitoring: faalende workflows direct signaleren via alerts.

Belangrijkste 20%

  • Denk in trigger → stappen → actie; vrijwel elk proces past in dit patroon.
  • Bouw foutafhandeling in: retries, error-workflows en logging.
  • Test met echte data; randgevallen breken workflows, niet de happy flow.

Praktijkvoorbeeld (fictief)

een installatiebedrijf koppelt zijn websiteformulier via een webhook aan n8n. De workflow maakt een lead aan in het CRM, laat een LLM de aanvraag scoren op urgentie en budget, en stuurt bij een hoge score direct een bevestigingsmail plus een taak naar de verkoper. De eigenaar bespaart wekelijks een halve dag handmatig opvolgwerk.
